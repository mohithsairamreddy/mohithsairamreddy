# Hi, I'm Mohith 👋
 
**Data Engineer (SDE-2)** — I build and own real-time data platforms in production: CDC pipelines, dimensional warehouses, and the monitoring that keeps them trustworthy.
 
## 🔧 What I do
 
- **Own a production Kafka CDC platform** streaming PostgreSQL changes into Snowflake — ~8M events/day across 26 connectors, validated for **zero data loss across 8 fault-tolerance scenarios**
- **Model dimensional warehouses** (Kimball) serving 30,000+ users across 500+ institutions, transformed and tested with dbt
- **Build reliability tooling** — heartbeat-based silent-failure detection, DLQ handling, Grafana monitoring, day-end health checks
- Led a 23-table Data Mart migration; manage 70+ tables across Dev/Test/Prod with Snowflake RBAC
## 🏗️ Current project
 
**Indian Markets Lakehouse** — a Databricks / Delta Lake medallion architecture (bronze → silver → gold) over 5 years of NSE equities, commodities, and forex data (~3M rows). Auto Loader ingestion, MERGE upserts, OPTIMIZE + Z-ORDER, quarantine tables for schema-mismatched records, and a parser registry that handles source-format changes over time.
